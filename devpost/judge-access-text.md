**Try it online:** https://handful-is-not-a-unit.vercel.app (confirm this is the final address before pasting)

**Demo mode opens first, with no sign-in.** Open the link, tap **New**, give the dish a name, and you will see a box that says "Demo mode". Tap any of the three sample sentences: the app reads it and builds ingredient lines, estimates and steps. These are answers recorded from Gemini ahead of time, so nothing you tap or type in demo mode is sent anywhere. Typing or speaking your own sentence in demo mode is politely refused.

**To use the real helper** (the live Gemini reading, with your own words or your voice): on the same screen, tap **Have an access code?**, enter `<CODE>` and tap **Unlock**. The box then says "Access code accepted". The code only lasts for that browser tab; closing the tab returns to demo mode, and **Back to demo** does the same at any time.

**Please keep to short sentences.** The access code lets the app call the owner's Gemini key, so it is meant for judging only. Voice works in Safari and Chrome; typing always works.
